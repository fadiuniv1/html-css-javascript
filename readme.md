# 📘 LearnHub – Mini Course Platform

A small web project that showcases online courses, previews course media, and includes a simple form to apply for a course.

---

## 📄 Pages

### **index.html – Courses**
• Shows available courses  
• Each course has an image, description, and price  
• “Buy Now” button leads to the form  
• Uses a 3‑column Holy Grail layout  

### **gallery.html – Media**
• Displays course‑related images, video, and audio  
• Uses CSS Grid  
• Demonstrates support for multiple media types  

### **form.html – Apply**
• Simple form with 5 input types  
• JavaScript displays the submitted data on the page  
• No page reload  
• Works with dark mode  

---

## 🎨 Features
• Light/Dark mode toggle  
• Responsive/adaptive layout  
• Custom cursor loaded from `/media/`  
• Clean structure with separate folders for CSS, JS, and media
