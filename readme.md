## 📝 Project Overview
This project is a dynamic web application developed as a final assignment. It demonstrates the use of semantic HTML5, responsive CSS layouts (Flexbox/Grid), and JavaScript for interactive features.

## 🛠️ Key Features
* **Holy Grail Layout:** The main structure is built using a CSS Flexbox layout to ensure a consistent header, navigation, and sidebar system.
* **Responsive Design:** Using Media Queries, the layout is optimized for mobile devices, ensuring content is readable on any screen size.
* **Theme Toggle:** A JavaScript-powered button to switch between light and dark themes.
* **Interactive Form:** A dedicated page with 5 types of inputs that captures data and displays results dynamically on the page.
* **Media Gallery:** A grid-based gallery for displaying various media items.

## 📂 File Structure
- `index.html` - The main homepage and entrance to the site.
- `gallery.html` - A responsive gallery containing media items (images/video).
- `form.html` - A functional contact and data submission form.
- `style.css` - Centralized styling for all pages, including responsive rules.
- `script.js` - Logic for the theme toggle and form data processing.
