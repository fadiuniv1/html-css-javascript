## Project Overview
This project is a dynamic web application built using HTML5, CSS3, and JavaScript. The goal was to create a responsive site that uses a clean layout and dynamic content handling.

## Key Features
* **Holy Grail Layout:** I used CSS Flexbox to create the main structure (Header, Nav, Main, and Sidebars).
* **Responsive Design:** Using Media Queries, the site is optimized for mobile screens. On small devices, the content stacks vertically, and the `Main` section appears first for better usability(Holy Grail req).
* **Dark Mode Toggle:** I wrote a JavaScript function that allows the user to switch between light and dark themes instantly.
* **Dynamic Form:** The form uses 5 different input types. When submitted, JavaScript captures the data and displays it on the page dynamically without refreshing.
* **Media Gallery:** A grid-based gallery that displays images and video with titles and descriptions.



## Future Ideas (Featured)
* **HyperOS Theme:** I plan to implement a high-contrast dark theme inspired by Xiaomi's HyperOS in a future version.
* **Local Storage:** Adding the ability to save form submissions even after closing the browser.

## File Structure
* `index.html` - The main homepage.
* `gallery.html` - The media gallery page.
* `form.html` - The interactive data form.
* `style.css` - All the styling and responsive rules.
* `script.js` - The logic for the theme and form.
